# 人话正误对照库（写之前读一遍，写完逐条对）

用法：这不是禁词表，是**句法模板**。写每一句时先问"这句属于哪一类"，再照"对"的那一列写。
全部例子都用普通行当（灶房、修车、木工、柜台），不放具体作品与人名。

## A. 物件、零件不能当施事（本事、关系只能落在人身上）

| 错 | 对 | 错在哪 |
|---|---|---|
| 这勺，谁教的？ | 这手艺，跟谁学的？ | 勺不会教人；本事在人身上 |
| 这把刀认他。 | 掌柜把刀递到他手上。 | 刀不会认人；关系是人给的 |
| 牌子知道他姓什么。 | 牌子上刻着他姓什么。 | 牌子不会知道，刻才是人做的 |
| 锅自己会看火。 | 他盯着锅里的油，油一冒烟就把锅离火。 | 锅不会看，人在看 |
| 这口锅等他十年了。 | 这口锅在灶台上搁了十年，没人动。 | 锅不会等 |
| 匾替他记着这件事。 | 匾背上刻着这件事。 | 记是人做的，刻是留下的痕 |

## B. 眼睛、耳朵、手、尾巴不能自己做事（零件不能代替人）

| 错 | 对 |
|---|---|
| 眼睛落在他那把勺上。 | 学徒低头看他的勺。 |
| 耳朵竖起来了。 | 他把耳朵转向灶口，听油响。 |
| 手自己伸过去把火关了。 | 他伸手把火关了。 |
| 尾巴替他挡了一下。 | 他用尾巴扫开案板上的水。 |
| 目光扫过整间灶房。 | 他站在门口，把灶房看了一遍。 |
| 指头先知道了。 | 他手指按在锅沿上，试出锅热了。 |

## C. 看着像动作、其实没写落点的词（一律换成手在哪）

| 错 | 对 |
|---|---|
| 掌柜捧铜牌递到他胸前。 | 掌柜把铜牌放到案板上，牌面朝他。 |
| 他把勺往膝盖上一横。 | 他把勺放在膝盖上。 |
| 肩往下塌了一块。 | 肩膀塌下去。 |
| 他把碗往桌上一墩，碗里的汤一颤。 | 他把碗放到桌上，汤晃出来一点。 |
| 铜牌被他缓缓推回去。 | 他用勺背把铜牌推回柜台。 |
| 他微微一怔。 | 他停了一下，没接话。 |

## D. 看不见的东西不能当主语

| 错 | 对 |
|---|---|
| 葱香顶上来。 | 油响了一声，锅里的葱段翻了个身。 |
| 气氛冷下去。 | 没人说话，掌勺的把勺子放下了。 |
| 压力压过来。 | 掌柜站在他背后，没走。 |
| 一股热气扑出来。 | 蒸笼盖一掀，白汽冒到他脸上。 |

## E. 一句只放一件事，因必须有人做（禁逗号硬接因果）

| 错 | 对 | 错在哪 |
|---|---|---|
| 他把勺搁在灶沿上，三口灶一起响。 | 三口灶上的油锅一起响。他把勺搁在灶沿上。 | 锅是灶上烧着才响，不是放勺才响 |
| 他把门推开，屋里亮了。 | 他把门推开。屋里的灯还亮着。 | 亮是灯亮，不是推门 |
| 他添了把柴，汤就滚了。 | 他添了把柴。过一会儿汤滚起来。 | 少了"过一会儿"，两件事被并成因果 |
| 他一句话没说，全屋都静了。 | 他一句话没说。屋里的人也不说话了。 | "静了"没人做 |
| 他一进门，所有人都站起来。 | 他一进门。桌边的人站起来两个。 | 前句像"进门"直接导致起身 |

## F. 文学腔、比喻、副词（全部删掉，换成能拍到的）

| 错 | 对 |
|---|---|
| 声音平得像在说别人的事。 | 他说这话时没抬头。 |
| 他缓缓抬起头。 | 他抬起头。 |
| 时间仿佛停了一下。 | 他停住手，锅里的油还在响。 |
| 那口锅像一个老头。 | 锅底一圈黑，锅沿豁了个口。 |
| 他心里像被什么扎了一下。 | 他把勺放下，手在围裙上擦了两下。 |

## G. 台词要有人真这么说过（放进谁嘴里都成立＝AI 味）

| 错 | 对 | 错在哪 |
|---|---|---|
| 师父，我懂了什么叫传承。 | 咸了，下回少半勺。 | 没人这么说话 |
| 我一定会把您的手艺传下去。 | 这勺我用着顺手。 | 承诺式台词，没人这么讲 |
| 你根本不懂我在想什么。 | 那天你为啥只骂我？ | "不懂我"是作者的话 |
| 我们之间，早就不是师徒了。 | 账结了吧。 | 关系结论没人当面说 |
| 这些年，您辛苦了。 | 你头发白了。 | 客套话不是生活里的话 |
| 命运真会开玩笑。 | 又是这家店。 | 总结句，不是人话 |

## H. 状态直说、解释旁白、总结升华（一律删）

| 错 | 对 |
|---|---|
| 他很难过。 | 他把勺放下，没再看那口锅。 |
| 其实他早在盐里放了糖。 | （删掉，让食客吃一口吐出来） |
| 原来师傅一直在暗中照顾他。 | （删掉，让勺柄上的刻痕自己说话） |
| 他终于明白了这份苦心。 | 他把勺柄抵在额头上，肩膀塌下去。 |
| 这就是手艺的分量。 | （删掉） |
| 从此，他成了这条街上最好的掌勺。 | 门框上的牌子换了一块新的。 |

## 写稿时的固定动作（顺序不许颠倒）

1. 每段先填五行：**谁／哪只手拿什么／给到谁·落在哪／本段谁占上风／一句谁对谁说的话**。
2. 五行齐了才扩成散文；扩的时候只加能被拍到的：位置、朝向、手上的动作、声音。
3. 散文写完，跑 `tools\human_regress.py`；不过就改那一句，不整篇重写。
4. 逐句念；念着别扭就换成这行当里的人的原话。

（本文件缺省时，按 SKILL §7.6.8 的三条判据自判：动作能指到手／施事必须是人／一句一件事。）
