# storyboard-v17 · 一句话分镜脚本技能

给一句话，按导演的规矩往下写：**一句话 → 剧本 → 分镜脚本 → 文生图提示词**，三个阶段，每一步停下来等你点头。

不接模型、不要密钥、不起服务。贴进你常用的对话工具（豆包 / WorkBuddy / 龙虾类工具体系的技能目录，或人设框），或者本地命令行直接跑。

当前版本 **v2.9.58**，整包自检 **260 项全过**（解包即验，不是嘴上说）。

## 它主要治这几件事

AI 写分镜翻车基本就那几样，写过的都见过：

- 上一个镜头人还在门口，下一个镜头人就到屋里了
- 手里拎着的东西，下一镜没了
- 光一会儿从左打一会儿从右打，人脸朝向一会儿朝左一会儿朝右
- 台词一股机器腔，「在这个画面中我们可以看到」
- 画面里写「那年秋天」「前几天」这种根本拍不出来的时间
- 每镜十秒，镜数十八个，先定死数字再往里面硬塞剧情

这套东西不对症在提示词上堆字，而是把规矩写死，让不合格的直接过不去。

## 立住的几条硬规矩

1. **镜间接续只认画面里看得见的东西**——人、物、光、站位。靠声音接、靠联想接、靠比喻接，一律不算数。
2. **每写完一镜回读上一镜的结尾**：人站哪儿、脸朝哪边、手里拿什么、光从哪边来，一项一项对，对不上打回去重写。
3. **动作必须说清**：用哪只手、拿什么东西、从哪儿移到哪儿。「拎着东西走过去」这种含糊话判不合格。
4. **时间必须是可拍的具体时点**，抽象时间词禁止进画面。
5. **台词限字数、限人称**，书面腔和硬升华的句子不给过，金句留给配角说。
6. **镜数和秒数不预设**：先写定这一镜演什么，再由内容推它演多久，单镜上限 15 秒、无下限；剧本切几段就是几镜。总时长只做校验。
7. **因果链也得立住**：钱款、承诺、交接、职业、算术有一处断链就退回；「为什么非得今天、非得这个人」交代不清也退回。
8. **不许自动往下冲**：剧本出完停下等确认 A，点头才出分镜，再停等确认 B，点头才出文生图提示词。改几遍停几遍。

## 包里有什么

```
storyboard-v17/      规则文档 SKILL.md + 参考文件（三阶段全部判定标准）
tools/               33 个检查脚本 + 词表（出稿、门禁、自检、衔接、逻辑链、文体）
爆款储备库.md         11 个子类各 ≥3 个真实案例，工具跑之前会读
output/              两份固定示例稿（自检用的考题，用来验证机器能不能揪出前后矛盾）
```

## 怎么跑

解压到任意目录，先跑全量自检确认整套工具正常：

```
python tools/selftest.py
```

看到 `结论：260/260 通过` 就说明可用。

日常出稿：

```
python tools/storyboard.py stage1 --idea "一句话题材" --run output/你的目录
```

然后按 `confirm A → stage2 → confirm B → stage3 → confirm C` 走。

## 自检

整包 **260 项，全过**。覆盖结构禁词、抽象时间、情绪结论、心理活动、比喻、含糊动作、日期混进画面、因果链断裂、动机不成立、题材只在设定里没真落地这几类，报错会定位到具体行。

## 先说清楚的三件不好的事

1. **我只在本地命令行把整条链路跑通验证了**，各家对话工具里的真跑证据还没留。这些规矩最后还得真人拿去试拍才算数。
2. 这份包里的爆款库和 tools 是母版，路径按我这台机器写的。换机器没有这套库时，按 `SKILL.md` 里的换机降级规则走：规则照用，爆款六维改成现场联网采三条同类再算，并在交付里注明「本次未接库」。
3. 它只管上游脚本质量，**不出图、不剪辑、不接视频模型**。成稿是可以直接复制去用的完整脚本，不绑定任何出图工具。
